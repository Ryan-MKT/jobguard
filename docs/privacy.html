求職門神 隱私權政策

最後更新：2026-05-18

不收集任何個人資料

求職門神 Chrome 擴充功能完全在使用者瀏覽器本機運作。我們不收集、不傳送、不儲存任何使用者的個人識別資訊、瀏覽紀錄、或求職活動。

資料如何運作

  • 違規公司資料來自政府公開資料（新北市資料開放平台），定期下載到使用者瀏覽器的 IndexedDB
  • 使用者瀏覽求職網站時，extension 在本機比對公司名 → 顯示風險資訊
  • 所有查詢都在本機完成，不會傳送任何資料給開發者或第三方

外部請求

本 extension 僅向以下公開來源發送請求：

  • GitHub Pages（取得最新違規資料集）
  • Google News RSS（查詢公司相關新聞）
