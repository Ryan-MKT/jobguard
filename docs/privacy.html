求職門神 JobGuard 隱私權政策

最後更新：2026-05-19

一句話總結

求職門神不收集、不傳送、不儲存任何使用者個人資料。所有公司名比對都在你的瀏覽器內完成。

我們不蒐集的資料

類別蒐集狀態
個人識別資訊（姓名、email、電話）不蒐集
驗證資訊（密碼、cookies、token）不蒐集
瀏覽歷史不蒐集
查詢的職缺、公司、關鍵字不蒐集
點擊、輸入等使用者活動不蒐集
位置資訊不蒐集
財務、付款資訊不蒐集

資料如何運作

  • 本擴充功能從公開資料源（見下方）下載風險資料，存到使用者瀏覽器本機的 chrome.storage 與 IndexedDB
  • 使用者瀏覽 104 等求職網站時，extension 在本機比對公司名，顯示對應的風險徽章
  • 所有處理過程不會將任何使用者資訊（包含瀏覽中的網址、職缺、公司名）傳送給開發者、伺服器或第三方
  • 本機快取的資料完全在使用者瀏覽器內，解除安裝擴充功能即清除

外部請求說明

本擴充功能僅向以下公開來源發送 HTTP 請求：

網域用途請求內容
ryan-mkt.github.io 下載每日更新的政府違規資料 JSON 固定 URL，不含使用者識別資訊
news.google.com 查詢公司名對應的公開新聞 RSS 僅含公司名關鍵字，不含使用者識別資訊

資料來源（皆為公開資料）

  • 新北市資料開放平台 — 違反勞動基準法事業單位（CC-BY 4.0）
  • 司法院判決書開放資料（勞資相關判決）
  • Google News RSS（公開新聞）

第三方服務

本擴充功能不使用任何分析工具（Google Analytics、Mixpanel 等）、廣告 SDK 或追蹤腳本。

與其他平台的關係

求職門神為獨立開源專案，非 104 人力銀行官方產品，與 104、1111、yes123 等求職平台無任何合作或從屬關係。所有顯示資料皆來自公開資料源的整理呈現，不構成任何法律或就業建議。

變更通知

若本政策有重大變更，將於本頁面更新並調整「最後更新日」。重大變更會在發佈新版本時於 Chrome Web Store 更新說明告知。
